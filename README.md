# Yatube API

API для социальной сети Yatube. Проект предоставляет REST API для управления постами, комментариями и подписками с JWT-аутентификацией.

## Описание проекта

Yatube API - это бэкенд-часть социальной сети, которая позволяет пользователям:
- Публиковать посты с текстом и изображениями
- Просматривать посты других пользователей
- Оставлять комментарии к постам
- Подписываться на других авторов
- Просматривать список своих подписок
- Искать по подпискам

Проект реализован с использованием Django Rest Framework и использует JWT-токены для аутентификации.

### Технологии

- Python 3.12+
- Django 5.1.1
- Django REST Framework 3.15.2
- Djoser 2.3.1 (аутентификация)
- PyJWT 2.10.1 (JWT токены)

### Функциональные возможности

- **JWT аутентификация** - безопасная авторизация пользователей
- **Посты** - CRUD операции с постами
- **Комментарии** - CRUD операции с комментариями к постам
- **Подписки** - возможность подписываться на авторов
- **Поиск** - поиск по подпискам
- **Права доступа** - только авторы могут редактировать и удалять свой контент
- **Пагинация** - постраничный вывод результатов (10 постов на страницу)

## Установка и запуск

### Требования

- Python 3.12+
- pip (менеджер пакетов Python)

1. **Клонируйте репозиторий:**
```bash
git clone <url-репозитория>
cd yatube_api
```

2. **Создайте виртуальное окружение:**
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

3. **Обновите пакетный менеджер:**
```bash
python -m pip install --upgrade pip
```

4. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

5. **Выполните миграции:**
```bash
python manage.py makemigrations posts
python manage.py migrate
```

6. **Создайте суперпользователя (опционально):**
```bash
python manage.py createsuperuser
```

7. **Запустите сервер:**
```bash
python manage.py runserver
```


### Сервер будет доступен по адресу: http://127.0.0.1:8000/
### API документация будет доступна по адресу: http://127.0.0.1:8000/api/v1/

## Примеры запросов

### Получение токена:
```bash

POST /api/v1/jwt/create/
{"username": "user", "password": "pass"}
```
### Создание поста:
```bash

POST /api/v1/posts/
Authorization: Bearer <token>
{"text": "Мой пост", "group": 1}
```
### Подписка на пользователя:
```bash

POST /api/v1/follow/
Authorization: Bearer <token>
{"following": "username"}
```
### Поиск по подпискам:
```bash

GET /api/v1/follow/?search=ivan
Authorization: Bearer <token>
```
### Права доступа

    Аноним: только GET на /posts/, /groups/, /comments/

    Auth: всё, кроме редактирования чужого контента

    Автор: полный контроль над своими постами и комментариями

    Подписки: только для авторизованных пользователей

### Коды ответа

    200 - успешно

    201 - создано

    400 - ошибка валидации

    401 - не авторизован

    403 - нет прав

    404 - не найдено
